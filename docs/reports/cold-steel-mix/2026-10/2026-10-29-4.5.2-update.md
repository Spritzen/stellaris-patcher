# Update check: Cold Steel Mix, 4.5.2, 29 October 2026

**Four mods changed: Universal Resource Patch, Diverse Rooms and both dark
ambient soundtracks. The game is still 4.5.2. All 30 fixes still build, and
the patch's 73 files match the written patch byte for byte. Nothing clashes.
Diverse Rooms added an event that can't work, but it changes nothing in play.
No fix is proposed. Steam posted the 4.5.3 open beta notes. 4.5.3 isn't
installed, and is due to go live on 4 November. Cold Steel's build is older
than all four updates and needs a rebuild.**

- **Universal Resource Patch adds two resources to its topbar lists.**
  `lore_illicit_goods` is in all six files, and `biomass_typh` (Typhoeus
  Swarm) is in one. No playset mod defines either, so they join the
  "resources not installed" entries the
  [first error report](2026-10-03-errors.md#universal-resource-patch)
  found harmless: about 7 more on each load.
- **Diverse Rooms adds a country event that can't work.** On
  `on_country_type_changed`, `country_change_event.1` runs `set_room` and
  `update_country_designation`. The game has neither effect. Its 4.5.2
  `effects.log` lists only `room_name_override` for rooms. No file declares
  the `country_change_event` namespace either. The event changes nothing,
  and the next error log will likely show it. The game's own two events on
  that on_action still run, as on_action event lists merge.
- **Diverse Rooms also redrew the megacorp room and added two rooms.**
  `megacorporation_room.dds` is new art at the same path, picked for
  megacorp governments as before. `caravaneers_room.dds` and
  `megacorporation2_room.dds` are new, and no selector picks them. No other
  mod has these files.
- **The soundtracks only moved their `supported_version`** from v4.5.1 to
  v4.5.2. Their music and song lists are unchanged.
- **Cold Steel's build is from 18 October, 16:52.** Steam updated the
  soundtracks on 23 October, Diverse Rooms on 25 October and Universal
  Resource Patch today. Rebuild it in Cold Steel before playing.

## What to do next

1. **Rebuild Cold Steel Mix in Cold Steel**, so the build carries the four
   updates. Our patch doesn't need writing again.
2. **No fix proposed.** Diverse Rooms' event is the mod's own bug. It
   changes nothing a player would see, so it isn't worth a line in "Left to
   the authors" ([decision 41](../../../decisions.md)). Its author updated
   four days ago, so a fix may follow. You could tell them on its Workshop
   page.
3. **Look for Diverse Rooms' event in the next game report.** Expect load
   entries for `set_room`, `update_country_designation` or the namespace,
   and none during play beyond those.
4. **Run the update check again when 4.5.3 goes live.** Several of its notes
   touch what the patch fixes. See [4.5.3 open beta](#453-open-beta).
5. **Accept the check** with `check-update --accept`, so this baseline holds
   the four updates.

## How it was worked out

- `check-update --notes`, in `~/.cache/stellaris-patcher/checks/2026-10-29_1827/`.
- The 4.5.3 open beta announcement in `notes/` was read.
- Each changed mod's baseline was unpacked from `snapshots/` and compared
  with the installed copy, file by file. Files the snapshot doesn't keep
  were compared by size with the baseline's record.
- Diverse Rooms' two effects were looked up in the game's 4.5.2
  `logs/script_documentation/effects.log`, and its namespace in every
  game and playset event file.
- Every playset mod was searched for `on_country_type_changed`, room
  textures and selectors, `resource_groups`, `lore_illicit_goods` and
  `biomass_typh`.
- Update times came from `appworkshop_281990.acf`, and were compared with
  Cold Steel's build.
- The fixes' files were built in memory and compared with
  `~/.local/share/stellaris-patcher/mods/cold_steel_mix_patch/`.
