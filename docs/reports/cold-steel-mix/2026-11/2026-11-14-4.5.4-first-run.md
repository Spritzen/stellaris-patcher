43 is why.** It was a new galaxy, Commonwealth of Man, from 2200.01.01 to

an astral rift in the player's space. Earlier runs logged it too. No fix is
proposed. The patch was in the build, and every copy it ships won. The user

## How it was worked out

- `error.log` was read with our
  [error_log.py](../../../../src/stellaris_patcher/paradox/error_log.py) and
  split by time with `game.log`: the game started at 19:46:30 and made the
  galaxy at 19:47:18. The last entry is at 19:49:03.
- Entries were grouped by source and text. Universal Resource Patch's
  `strategic_resources_gui_group.cpp` entries, and the duplicate object,
  entity, section template, event and variable notices, were counted apart.
- `dlc_load.json` showed the one mod loaded. Cold Steel's build record
  (`builds/d8f5e037….json`) gave the build time, the patch's place last,
  and the source of each file. Each patch, Stellar AI, Apocryphos and
  Kammarheit file in the built mod was compared with its source.
- Each duplicate object notice was matched to the files the patch ships.
- The raw log was searched for the names the fixes removed.
- The message text was searched for in the game's and every playset mod's
  localisation, and its key and event in their scripts.
- The ironman save was unpacked to a scratch folder. Its country, government,
  home planet and start system were read.
