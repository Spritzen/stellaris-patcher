# Four years on 4.6.0: Cold Steel Mix, 24 November 2026

**The first run with fixes 46, 47 and 48 found one problem the patch made.
Fix 47's copies of Real Space's two Scion systems break Real Space's
`federations_initializers.txt`. The game reads the copy in the patch first,
logs the one in Real Space's file as a duplicate, and then rejects every
system after it in that file. Five systems are lost, among them the
Shattered Ring origin's only home system and the Void Dweller origin's
Sol. Real Space's file
replaces the game's, so the game's copies are gone too. Nothing looked wrong
in four years as the United Nations of Earth, which uses neither origin.
Fixes 46 and 48 work: the Unbidden's shader errors are gone, and Stewart's
Resolve spawned.**

- **Fix 47 breaks five systems.** `An initializer called "scion_fallen_1"
  already exists`, then `Unexpected token` for each of the six systems after
  it in Real Space's file. The patch has its own `scion_fallen_2`, so five
  are lost: `shattered_ring_start`, `mega_shipyard_init_01`,
  `planet_with_too_many_moons_system`, `wenkwort_initializer` and
  `sol_system_void_dweller_system`. See [Fix 47 and Real Space's
  file](#fix-47-and-real-spaces-file). Changing the fix is proposed.
- **Fix 46 works.** No `Failed to create material` and no mesh without a
  model. The last run had 9. No Unbidden came in four years.
- **Fix 48 works.** The save's `system_initializer_counter` lists
  `stewarts_resolve_system`. The patch's `is_trinary` wins.
- **The Fallen Empire building order shows in play.** Real Space's
  `fallen_3` places three buildings before the zoned ones. Two of those then
  find the urban zone full and fall back to another slot. Each is still
  built.
- **The patch held otherwise.** The build's 69 patch files match our folder
  byte for byte. 73 problems in all, against 76 last run.

## Fix 47 and Real Space's file

**Fix 47 ships copies of Real Space's `scion_fallen_1` and `scion_fallen_2`
in a `!!_` file, so they're read first.** The game keeps the first copy of a
system, as the [merge rules](../../../reference/patch-rules.md) say. But
the second copy doesn't only lose. At 21:44:29 the game logs:

| Line in Real Space's file | Entry |
|---:|---|
| 1691 | `An initializer called "scion_fallen_1" already exists` |
| 1958 | `Unexpected token: scion_fallen_2` |
| 2403 | `Unexpected token: shattered_ring_start` |
| 2533 | `Unexpected token: mega_shipyard_init_01` |
| 2683 | `Unexpected token: planet_with_too_many_moons_system` |
| 3125 | `Unexpected token: wenkwort_initializer` |
| 3252 | `Unexpected token: sol_system_void_dweller_system` |

These are all seven systems from `scion_fallen_1` to the end of the file.
After the duplicate, the game rejects each system that follows. Events and
buildings don't do this: a duplicate there is only a notice. This is the
first time the patch has shipped a copy of a system another file also
defines. Fix 5's and fix 48's systems have names nothing else uses.

What's lost, as Real Space's copies replace the game's whole file:

| System | What it is |
|---|---|
| `shattered_ring_start` | The Shattered Ring origin's only home system |
| `sol_system_void_dweller_system` | The Void Dweller origin's Sol, for an Earth empire. Its other home system, `void_dweller_system`, comes earlier in the file and loads |
| `mega_shipyard_init_01` | A galactic landmark with a ruined Mega Shipyard |
| `planet_with_too_many_moons_system` | A misc system near the xenophobe Fallen Empire, which an event in `federations_events_2.txt` looks for |
| `wenkwort_initializer` | Wenkwort, a natural spectacle |

None of these spawned in this galaxy. That's expected if they're lost, but
they're rare anyway. The player's origin used neither home system. An
empire with the Shattered Ring origin, the player's or an AI's, would most
likely have no home system to start in, nor would an Earth empire with the
Void Dweller origin.

**The fix needs no duplicate.** Fix 32 meets the same problem with Starbase
Extended's modules by shipping the mod's whole file at its own path. The
patch loads last, so the game reads only the patch's copy. Done for Real
Space's `federations_initializers.txt`, that's about 3,300 lines of Real
Space's work, rebuilt from its file at every build. The Scion systems get
the same four lines each as now, and nothing else changes.

## The Fallen Empire building order

`game.log`, at galaxy creation:

```
add_building: no room for building 'building_fe_clinic_2' in district '' and zone 'zone_urban' on planet 'Mother' at  file: common/solar_system_initializers/fallen_empire_initializers.txt line: 1060, falling back to add_building = <key>
```

and the same for `building_dimensional_fabricator` at line 1064. Both lines
are in Real Space's `fallen_3`. It places the Ancient Palace, Stronghold and
Dome first, then three urban buildings. The game's 4.6 copy places the
zoned buildings first. "Mother" is a Planetary Diversity wet gaia world, a
Fallen Empire's homeworld.

So the order does change something: two buildings miss their zone.
`falling back to add_building = <key>` means each was still placed, in the
zone with a free slot and the highest AI priority, as 4.6's notes describe.
Where they landed wasn't found: the save's zone records for Mother's city
district are empty. One Fallen Empire of the galaxy's few was affected.

## How it was worked out

- `error.log` read with our
  [error_log.py](../../../../src/stellaris_patcher/paradox/error_log.py),
  split by time with `game.log`, and grouped by source and text. Resource
  and override notices were counted apart, as last run.
- Each entry's file was traced through the build record of 21:43. The
  `Unexpected token` lines were matched to the top-level systems of Real
  Space's `federations_initializers.txt`, line by line.
- The build's 69 patch files were compared with our folder.
- The `game.log` fallbacks were traced to `fallen_3` in Real Space's
  `fallen_empire_initializers.txt`, and its building order compared with
  the game's.
- The ironman save was unpacked to a scratch folder. Its
  `system_initializer_counter` was read, and the planet called Mother found.
