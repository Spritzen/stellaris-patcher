# Update check: Cold Steel Mix, Stellar AI 0.21, 24 November 2026

**Stellar AI updated to 0.21 for 4.6.0 today. It no longer breaks 4.6's
economy, so it can stay on: item 1 of the
[4.6.0 update report](2026-11-23-4.6.0-update.md) is withdrawn. It no
longer ships job files, so the game's Culture Worker jobs win and can be
worked. Its zones, personalities and strategic resources are now 4.6's
files with its AI changes added. No other mod and no game file changed. All
of that report's other proposals still stand, and none has been acted on
yet. They're listed again below, renumbered. Fixes 37 and 41 still build:
fix 37's faculty now carries Stellar AI's new AI weight. Cold Steel's build
predates the game and nine mod updates, so it needs a rebuild before play.**

- **Culture Workers work again.** Stellar AI 0.21 dropped its three job
  files: `01_ruler_jobs.txt`, `02_specialist_jobs.txt` and
  `04_gestalt_jobs.txt`. `culture_worker`, `culture_worker_gestalt` and
  `bureaucrat` come from the game now. Unity buildings give unity again.
- **Its whole-file copies are 4.6's now.** `00_zones.txt`,
  `00_personalities.txt` and `00_strategic_resources.txt` are the game's 4.6
  files with Stellar AI's changes, each marked with a comment. The zones use
  `included_buildings` and have `zone_rural_fortress`. The personalities
  have all 15 Ideology acceptances. The strategic resources have
  `willpower`. Every line it changes is an AI weight or value.
- **Its new override files change only the AI.** Stellar AI now replaces 48
  buildings, 24 colony types, 7 war goals, 11 technologies and a few others
  by name, in `~stellarai_…` files. Against 4.6's copies they lack only AI
  weights, and an `OR` in four buildings that limits where the AI builds.
  A player passes that `OR` through `is_ai = no`. Its new building guard is
  also AI-only. `wg_force_ideology` keeps Force of Will's flag.
- **Planetary Diversity's job swaps now take effect.** 13 of its jobs used
  to lose to Stellar AI's job files. They now replace the game's, and only
  add its planet-specific swaps. They drop three comments, nothing else.
- **The patch is unchanged but for fix 37's AI weight.** A fresh build
  makes 57 files, as on 23 November. Fix 37 copies Stellar AI's faculty, so
  its `ai_weight_coefficient` is now `@stellarai_research_building_tier1_coefficient`,
  a global variable Stellar AI defines. Fix 41's file is the same byte for
  byte.

## How it was worked out

- `check-update --notes`, in `~/.cache/stellaris-patcher/checks/2026-11-24_1919/`.
  No new patch notes, no game file changed, one mod changed.
- Stellar AI's 0.14.4 snapshot and the game's 4.6.0 snapshot were unpacked
  from `snapshots/`. Each Stellar AI file at a game path was diffed with the
  game's.
- Every object Stellar AI defines that the game also defines was read with
  `read_definitions` and compared line by line with the game's 4.6 copy,
  comments and whitespace left out. The winner of each came from the
  layers with its folder's merge rule.
- The written patch's objects were matched to Stellar AI's.
- The patch was built in memory, and fixes 37 and 41's files compared with
  the written patch.
- The 13 new Planetary Diversity diffs were read for lines it drops.

## Limits

- **Nothing about play.** Whether Stellar AI plays 4.6 well needs a run.
- **AI values weren't judged.** Its changed weights, budgets and defines
  are its own design. Only lines a player would notice were looked for.
- **Localisation wasn't compared.** Stellar AI's English file adds its own
  keys. A replaced game key would show only in game.
