# Update check: Cold Steel Mix, 4.6.0, 23 November 2026

**Stellaris went from 4.5.4 to 4.6.0 "Corona Borealis", with the Willpower
expansion, which is installed. Planetary Diversity's seven mods and More
Events Mod updated for 4.6 on release day. The other 18 haven't. The
playset isn't ready to play. Stellar AI's whole-file copies of the job,
zone, personality and strategic resource files break 4.6's economy: every
unity building now gives Culture Worker jobs, and with Stellar AI no pop
can work them. Switching Stellar AI off until it updates is proposed. UI
Overhaul Dynamic hides most of Willpower's interface. 30 of the 32 fixes
build. Fixes 15 and 42 are left out because the mods now do what they did.
Five small fix changes and one new fix are proposed. Cold Steel's build
predates the game and all eight updates, so it needs a rebuild before
play.**

- **Stellar AI breaks unity.** 4.6 brings Culture Workers back. The
  Autochthon Monument, Heritage Site, Hypercomms Forum, their gestalt and
  corporate versions, Galactic Memorials and the new ideological buildings
  now give Culture Worker jobs, in place of their old civilian bonus.
  Stellar AI's `culture_worker` is a 4.5 placeholder with
  `possible = { always = no }`, so no pop can take the job. Its gestalt
  jobs file has no `culture_worker_gestalt` at all. Its zones use the
  `include` key 4.6 renamed, its strategic resources lack Force of Will's
  `willpower`, and its personalities lack Ideology acceptance. See
  [Stellar AI](#stellar-ai).
- **UI Overhaul Dynamic hides Willpower.** Its copies of 22 windows lack
  the Ideologies tabs, the ideology map mode button and the megastructure
  Modules tab, which Galactic Hall chambers need. See
  [UI Overhaul Dynamic](#ui-overhaul-dynamic).
- **Two game triggers were renamed, and two mods still use the old names.**
  4.6 renamed `has_megacorp` and `has_not_megacorp` to `has_megacorp_dlc`
  and `has_not_megacorp_dlc`. Real Space's Chors Compass, the Caravaneers'
  home system, has odds 0 plus 100 only through `has_megacorp`, so it may
  never spawn. Diverse Rooms' five prescripted empires use the old names
  for `playable`. A small fix is proposed.
- **Planetary Diversity's Sol file now loses to Real Space's.** Its update
  moved its Sol systems to `sol_initializers.txt`, Real Space's path. Real
  Space's whole file wins, so PD's `sol_neighbor_t1_first_colony` is gone.
  More Events Mod's Eden Protocol and PD's habitat start still name it.
  Fix 5 can map it to Real Space's Alpha Centauri, as it does the others.
- **Fixes 15 and 42 are left out, as their cause is gone.** More Events Mod
  now uses the game's shield upkeep names. Planetary Diversity now ships the
  game's Volcanic Climate Mods. Only fix 42's ash and magma worlds are lost.
- **Starbases lose 4.6's Ideological Push.** Every starbase tier, orbital
  ring, the Hyper Relay and the Offworld Trading Company gain
  `ideological_push_mult` in 4.6. Fixes 28, 32 and 34 ship mods' copies
  without it. Each can take the game's new lines.
- **Three graphics losses.** Real Space's whole `pdxmesh.shader` lacks the
  shader the Unbidden's ships now use. System Scale's planet entities lack
  the Inquisitor city planet and ring world. Diverse Rooms lacks the
  Inquisitor room. See [The mod copies](#the-mod-copies).
- **The check missed the 4.6 notes.** It keeps only announcements with a
  version number in the title. "Stellaris: Willpower now available!" and
  Dev Diary #441, which holds the 4.6.0 release notes, have none. Both were
  read by hand from the archive. A change to the check is proposed.

## How it was worked out

- `check-update --notes`, in `~/.cache/stellaris-patcher/checks/2026-11-23_1902/`.
- The Willpower launch announcement and Dev Diary #441 were read in full
  from `~/.local/share/stellaris-patcher/notes/`, as the check's `notes/`
  had neither.
- The game's 4.5.4 baseline was unpacked from `snapshots/`, and every
  definition in it and in 4.6.0 indexed with `read_definitions`. Each new
  older copy was kept only if the game's object changed. For each kept one,
  the mod's own object was read and checked for every line 4.6 added.
- Every playset mod was searched for each name a Modding line renames or
  removes, and for `has_megacorp` and `has_not_megacorp`.
- The patch was built in memory, written to a scratch folder and compared
  with the written patch file by file. Each object it defines was matched
  to the game's 4.5.4 and 4.6.0 copies.
- Winners were read from the layers with each folder's merge rule. The same
  was done with Stellar AI skipped, and the patch built that way.
- Planetary Diversity's and More Events Mod's baselines were unpacked to
  compare their Sol files.

## Limits

- **Nothing about play.** No game was run on 4.6. Whether Stellar AI's two
  zones hold buildings, the Caravaneers spawn, and the Unbidden show, needs
  a run.
- **Engine changes don't show.** Docked repair, leader background choice,
  ideology spread and the AI's market trades are in the game's code.
- **Willpower's own files weren't read against each mod.** Only objects a
  mod copies were compared. A mod that changes something an Ideology tenet
  relies on, without copying it, won't show.
- **Steam's notes are preliminary.** Dev Diary #441's notes came four days
  before release. The forum's final notes may list more.
- **Message types show as one object.** The check names every message type
  `message_type`, so one mod's own messages look like a copy of the game's.
